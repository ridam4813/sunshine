# Sunshine Facility Management Services - Professional Booking Website

## Overview

A modern, professional website for Sunshine Facility Management Services that enables customers to easily book various facility management services online.

## Features

### 🌟 Key Features
- **Responsive Design**: Fully responsive on all devices (mobile, tablet, desktop)
- **Professional Navigation**: Sticky navbar with smooth scrolling
- **Service Showcase**: Display of 6 core services with attractive cards
- **Online Booking System**: Easy-to-use booking form with validation
- **About Section**: Company information and statistics
- **Contact Information**: Multiple ways to get in touch
- **Modal Confirmation**: Success confirmation for bookings
- **Mobile Menu**: Hamburger menu for mobile devices
- **Smooth Animations**: Modern animations and transitions

### 📋 Services Offered
1. **Cleaning & Maintenance** - Professional cleaning for all space types
2. **Repairs & Maintenance** - Expert maintenance and repair services
3. **Landscaping** - Outdoor space management and design
4. **Security Services** - 24/7 professional security solutions
5. **HVAC Services** - Climate control system management
6. **Electrical Services** - Complete electrical solutions

### 📝 Booking Form Fields
- Full Name (required)
- Email Address (required)
- Phone Number (required)
- Service Selection (required)
- Preferred Date (required)
- Preferred Time (required)
- Service Location (required)
- Additional Details (optional)
